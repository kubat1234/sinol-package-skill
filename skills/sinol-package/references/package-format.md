# Package format

## Files

```
abc/
  config.yml
  doc/abczad.tex  (+ abczad-en.tex …)  sinol.cls  languages/*.cls  logo.png
  in/  out/
  prog/abc.cpp         model solution (the one used to generate .out)
  prog/abc2.cpp …      other correct solutions
  prog/abcs1.cpp …     slow solutions          prog/abcb1.cpp …  wrong solutions
  prog/abcingen.cpp    generator               prog/abcinwer.cpp input verifier
  prog/abcchk.cpp      checker                 prog/abcsoc.cpp   interactor
  prog/abclib.cpp/.h   library (any names, listed in config)
  prog/gen.h           sinol-gen (generator)   prog/oi.h          oi::Scanner for inwer / checker
  [prog/testgen.hpp]   optional                 (shared files: copies from `_templates/<type>`)
```

Id: exactly 3 lowercase ASCII letters; every file in `prog/`, `doc/`, `in/`,
`out/` starts with it. sio2 detects an interactive task by the presence of
`<id>soc.*`.

## Tests

Name: `<id><group><suffix>.in`, regex `^abc([0-9]+)([a-z]?[a-z0-9]*)\.in$`.

| name | meaning | made by |
|---|---|---|
| `abc0.in`; `abc0a.in`, `abc0b.in` … if several | examples from the statement, group 0, 0 pts | `g.example(...)` |
| `abc1ocen.in`, `abc2ocen.in` … | public tests, group 0, 0 pts, contestants get them right away | `g.ocen(...)` |
| `abc1a.in`, `abc1b.in`, `abc2a.in` … | tests of group 1, 2, … | `g.group(k)` + `g.test(...)` |

All of them are generated by `sinol-make gen` and none is committed (`in/` and
`out/` hold only a `.gitkeep`, because sinol-make needs the directories). A
package **without an ingen** commits all its tests instead: `!*.in` in
`abc/in/.gitignore`, `!*.out` in `abc/out/.gitignore`.

`sinol-make export --export-ocen` (what `contest.py export-all` and the release
run) puts `abc0*.in` + `abc*ocen.in` (with outputs) into
`attachments/abcocen.zip`; every file in `attachments/` becomes a problem
attachment in sio2. Letters within a group must increase without gaps
(oi type check).

## dlazaw/ — files for contestants

`abc/dlazaw/` (optional, committed) holds the files contestants need:

- library task (`lib` template): `abclib.h`, a sample library, a sample wrong
  solution;
- interactive task (`soc` template): a sample interactor (or another helper
  program).

Files go straight into `dlazaw/`; if there is more than one test, the tests go
into `dlazaw/tests/`, next to the other files. Tests are optional and usually
differ from the package tests: they are in the format the sample library /
interactor reads (e.g. without the input guard of the real library, or with
the hidden data the interactor gets).

Export packs `dlazaw/` as `attachments/dlazaw.zip` **instead of**
`abcocen.zip`: with `dlazaw/` contestants get only what is in it, so add the
tests they should have by hand. Describe the contents in the statement.

## config.yml

sio2 keys:

| key | meaning |
|---|---|
| `title`, `title_en`, `title_<lang>` | task name (per language) |
| `time_limit` / `time_limits: {group: ms}` | ms; per-group overrides global |
| `memory_limit` / `memory_limits: {group: KiB}` | KiB (256 MB = 262144) |
| `scores: {group: points}` | group 0 is always 0 pts; oi: must sum to 100 |
| `subtask_dependencies: {g: [groups]}` | g is scored as if it also contained the tests of the listed groups (min of ratios); **not transitive**; no group 0; no cycles. Needs sinol-make ≥ 1.9.15 |
| `override_limits: {py: {time_limit, memory_limit}}` | per-language limits |
| `extra_compilation_files: [..]` | files copied next to the solution when compiling (library) |
| `extra_compilation_args: {cpp: [..]}` | extra compiler arguments, e.g. the library `.cpp` |
| `extra_execution_files: {lang: [..]}` | files available at run time |
| `library` | legacy single library name — prefer `extra_compilation_*` |
| `num_processes` | interactive: number of solution processes (default 1) |
| `testrun_soc` | interactive: interactor used for user test runs |
| `no_outgen` | sio2 does not generate outputs on upload |
| `fake_time` | `off` / `zero` / `random` — what `time()` returns to the solution (undocumented) |
| `submission_size_limit` | bytes (undocumented) |

sinol-make keys:

| key | meaning |
|---|---|
| `sinol_task_id` | the id — must match the directory |
| `sinol_contest_type: oi` | our convention (see Scoring) |
| `sinol_static_tests: ["abc0*.in"]` | hand-written test files that gen keeps; not used in our packages (examples are in the ingen) — only in packages without an ingen or old ones |
| `sinol_expected_scores` | written by `run --apply-suggestions`; never edit by hand |
| `sinol_latex_compiler` | `auto` / `pdflatex` / `lualatex` / `latex_dvi` |
| `sinol_total_score` | default 100 |

sinol-make **rewrites** config.yml (key order, drops comments) — don't rely on
comments there.

## Scoring (`oi`)

A test scores 100% if time ≤ TL/2, then linearly less down to 1 at TL; group
score = min over its tests (and over dependencies); total = Σ group points ×
ratio. With the noisy `time` tool keep every correct solution far below TL/2.
